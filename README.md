# OPTPY

Repositorio de la asignatura **Python**, optativa de **2.º de Desarrollo de Aplicaciones Web (DAW)**.

Aquí se recopilan las actividades, ejercicios y proyectos realizados durante la asignatura, junto con apuntes y recursos útiles para aprender y practicar Python.

## Contenido

> Esta sección se irá actualizando a medida que se añadan materiales al repositorio.

- **Apuntes y ejemplos:** conceptos y ejemplos vistos en clase.
- **Ejercicios:** prácticas para aplicar lo aprendido.
- **Proyectos:** trabajos y pequeños programas desarrollados durante el curso.

## Organización recomendada

Para que sea fácil encontrar cada material, se propone organizar el repositorio así:

```text
OPTPY/
├── README.md
├── apuntes/       # Notas y ejemplos de clase
├── ejercicios/    # Actividades y prácticas
└── proyectos/     # Proyectos de la asignatura
```

Las carpetas se pueden crear conforme se vayan necesitando. Si una actividad tiene instrucciones propias, puede incluir su propio `README.md`.

## Requisitos

- Python 3 instalado.
- Un editor de código, por ejemplo Visual Studio Code.

Para comprobar que Python está disponible, abre una terminal y ejecuta:

```bash
python --version
```

En algunos sistemas el comando puede ser:

```bash
python3 --version
```

## Ejecutar un programa

Desde la terminal, sitúate en la carpeta del archivo y ejecútalo con Python:

```bash
python nombre_del_archivo.py
```

## Objetivos de aprendizaje

- Practicar la sintaxis y las estructuras básicas de Python.
- Resolver problemas mediante programas sencillos.
- Organizar el código en archivos y proyectos.
- Familiarizarse con herramientas de desarrollo y control de versiones.
